# src/adl/serve

Interfaces for other agents, both thin layers over the data gateway. Nothing is hosted.

| File | What it does |
|---|---|
| `__init__.py` | Package marker |
| `mcp_server.py` | MCP server with five read-only tools bound to one identity; scripted demo |
| `a2a.py` | A2A agent card and JSON-RPC `message/send` endpoint with token-to-identity mapping; demo |
