## How to read these numbers

| Number | What it means | What it does not mean |
|---|---|---|
| Net value +$9,678 per 28 days | Mean paired difference over 30 simulated replications for eight stores | A measured result at a real grocer |
| 95% interval | Percentile bootstrap over replications | Uncertainty about the simulator itself |
| WAPE 31.9% | Weighted absolute percentage error on days that did not sell out | Accuracy on sold-out days (demand is unobserved there) |
| AUC 0.791 | The model ranks sell-outs above non-sell-outs 79% of the time | Calibrated probabilities (Brier 0.186 is worse than the base rate) |
| Cost $76 per 28 days | Assumed unit rates times measured usage | A quote or a bill |
| 14/14 attacks stopped | Every scripted attack refused with the expected code | Resistance to attacks not in the suite |
