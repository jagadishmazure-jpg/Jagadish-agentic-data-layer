# domains/insurance/knowledge

The insurance knowledge layer's source documents and the questions used to evaluate retrieval.

| File | What it does |
|---|---|
| `corpus.yaml` | 24 documents: claims policies (triage, fast track, complex unit, leakage, subrogation, audits, approval, fair claims, privacy), line and channel guides, region-scoped office profiles, closed-file reviews, and one message carrying a prompt injection |
| `eval.yaml` | 24 questions with the documents that answer them, used by `adl insurance retrieval` |
