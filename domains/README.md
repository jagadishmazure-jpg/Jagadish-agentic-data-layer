# domains

Data definitions per business domain: contracts, metrics and knowledge. Code lives in `src/adl/domains/`. Two domains are built; two are planned.

| File | What it does |
|---|---|
| `retail/` | Built: Wrenfield Grocers (fictional), stockouts and markdown |
| `mortgage/` | Built: Quillmere Home Loans (fictional), rate-lock fallout |
| `insurance/` | Planned: Ferrowind Insurance (fictional), claims triage and leakage |
| `healthcare/` | Planned: Halsey Vale Health (fictional), inpatient fall risk |
