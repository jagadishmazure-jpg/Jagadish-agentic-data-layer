# domains

Data definitions per business domain: contracts, metrics and knowledge. Code lives in `src/adl/domains/`. One domain is built; three are planned.

| File | What it does |
|---|---|
| `retail/` | Built: Wrenfield Grocers (fictional), stockouts and markdown |
| `mortgage/` | Planned: Quillmere Home Loans (fictional), loan pipeline and fallout |
| `insurance/` | Planned: Ferrowind Insurance (fictional), claims triage and leakage |
| `healthcare/` | Planned: Halsey Vale Health (fictional), inpatient fall risk |
