# domains/mortgage/knowledge

The mortgage knowledge layer's source documents and the questions used to evaluate retrieval.

| File | What it does |
|---|---|
| `corpus.yaml` | 24 documents: lock and extension policy, product and channel playbooks, region-scoped branch notes, and one message carrying a prompt injection |
| `eval.yaml` | 24 questions with the documents that answer them, used by `adl mortgage retrieval` |
