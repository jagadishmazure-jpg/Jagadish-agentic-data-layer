# infra/bicep/modules

Bicep modules called by `main.bicep`.

| File | What it does |
|---|---|
| `data.bicep` | Log Analytics, ADLS Gen2 with containers, Key Vault, AI Search, diagnostics |
| `identity.bicep` | Pipeline and agents managed identities and four built-in role assignments |
| `network.bicep` | VNet, NSG, private DNS zones and private endpoints (conditional) |
| `fabric.bicep` | Microsoft Fabric F2 capacity (conditional) |
